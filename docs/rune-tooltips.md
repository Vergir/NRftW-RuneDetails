# Rune tooltips: game text vs Rune Details

Generated by `tools/rune_table.py` from the mod's in-game self-test (Rune Details 0.1.0, game build 29466, 262 rune assets; 2 runes without details) and the English rune texts in `analysis/rune_inventory.csv`.

- **Game text**: the rune's description without its first line ("Slot this Rune into a … to gain the X Spell."). The rune screen shows only this part.
- **Rune Details adds**: what the mod appends to that text, in grey parentheses: `… on impact. (130/150/200% weapon dmg by charge)`. *(nothing)* = the mod adds nothing.
- **Cost**: from the rune's action data (cost + additional cost). The mod does not show it; it is here for context.
